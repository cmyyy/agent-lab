# Agent 知识库测试语料

## AI Agent 是什么

AI Agent 是能自主使用工具完成任务的智能系统。它通过观察环境、做出决策、执行动作来达成目标。
与普通程序的区别在于：Agent 能根据上下文动态决定调用哪个工具，而不是走写死的流程。

## Agent 的核心循环

Agent 主循环包含三步：调用大模型、解析模型输出（文本或工具调用）、执行工具并回填结果。
这个循环会一直重复，直到模型输出纯文本（即最终回答）或达到迭代上限。

## 工具注册与分发

工具的注册中心维护"工具名 → 实现函数"的映射。模型通过函数调用协议请求工具，
注册中心按名字找到实现并执行，任何异常都转换为结构化错误返回给模型，让模型自行调整。

## 上下文管理

当对话历史过长时，Agent 需要管理上下文窗口：滑动窗口保留最近的消息，
超长部分可以压缩成摘要。这是所有 Agent 框架都要解决的核心工程问题。

## 混合检索技术

知识库检索常用混合策略：关键词检索擅长精确匹配术语和缩写，语义检索擅长理解换说法的问题。
两者通过倒数排名融合（RRF）合并结果，再用重排序模型精排，选出最相关的片段。

## Python 异步编程

Python 的 asyncio 用事件循环调度协程，await 挂起当前协程让出控制权。
async/await 语法让异步代码看起来像同步代码，但底层是协作式调度。
